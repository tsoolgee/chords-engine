# אפיון ממשק — תוכנת אקורדים לשירים בעברית

המסמך מיועד לגרפיקאי ולמי שיבנה את הממשק. הוא מתאר **מה** צריך להופיע בכל מסך
ואיזה מידע המנוע מספק לכל רכיב. **איך** זה ייראה נשאר להחלטת הגרפיקאי.
השמות בסוגריים `כאלה` הם שמות השדות ב-JSON שהמנוע מחזיר. הפירוט הטכני נמצא ב-[API.md](API.md).

---

## 0. עקרונות

- **הכיוון הוא RTL מלא.** המילים בעברית, ושמות האקורדים באותיות לטיניות (Am7, F#m).
  בתוך דף ימין-לשמאל כל שם אקורד נשאר משמאל לימין.
- **אקורד יושב מעל אות.** לכל אקורד בשורה יש אינדקס אות (`char`), שסופר מתחילת השורה,
  כלומר מהקצה הימני. הממשק מודד את רוחב הטקסט עד האות הזאת וממקם את האקורד מעליה.
  כך אין צורך בגופן מונוספייס, ואפשר להשתמש בכל גופן עברי.
- **העבודה איטית, והממשק צריך להרגיש את זה.** ניתוח שיר של 4 דקות לוקח בערך 6–10 דקות
  במחשב חלש (i3 בלי כרטיס מסך), ורוב הזמן הולך על תמלול המילים.
  לכן צריך תור עבודות, פס התקדמות ברור ואפשרות להמשיך לעבוד בזמן שהניתוח רץ.
- **כל מה שהמנוע מזהה ניתן לתיקון ידני.** הזיהוי טוב אבל לא מושלם, והעורך הוא חלק מרכזי במוצר.
- **טרנספוזיציה, קאפו וכתיב הם הגדרות תצוגה.** הם לא משנים את השיר השמור: השיר נשמר בסולם
  המקורי, והמנוע מחשב כל תצוגה מחדש לפי בקשה.

## 1. ספריית השירים (מסך הבית)

| רכיב | תוכן | מקור |
|---|---|---|
| רשימת/רשת שירים | שם, מבצע, סולם, משך, תאריך עדכון | `GET /api/songs` → `title, artist, key, duration, modified` |
| תג "בלי מילים" | אם השיר נותח בלי תמלול | `has_lyrics = false` |
| חיפוש / מיון | לפי שם, מבצע, תאריך או סולם | בצד הממשק |
| כפתור "הוספת שיר" | גרירת קובץ או בחירת קובץ (mp3, m4a, wav, flac, ogg, opus, וגם וידאו) | ← מסך 2 |
| פעולות לשיר | פתיחה, מחיקה (עם אישור), ניתוח מחדש | `DELETE /api/songs/{id}`, `POST .../reanalyze` |
| מצב ריק | הסבר קצר + כפתור הוספה גדול | |
| מחוון מנוע | "המנוע פועל / לא פועל", "מודל עברית חסר" | `GET /api/config` → `whisper_ready` |
| עבודות פעילות | פס קטן שמראה שיר בניתוח ואחוז התקדמות, קליק פותח את מסך 3 | `GET /api/jobs` |

## 2. חלון "ניתוח שיר חדש"

| רכיב | אפשרויות | שדה ב-options |
|---|---|---|
| קובץ | שם הקובץ + משך | `path` |
| **מילים** (בחירה אחת) | ① לתמלל אוטומטית (ברירת מחדל) ② להדביק מילים נכונות (תיבת טקסט גדולה) ③ אקורדים בלבד | ② → `lyrics_text` ③ → `skip_lyrics: true` |
| הסבר להדבקה | "שורה בטקסט = שורה בדף. שורה ריקה = בית חדש." | |
| דיוק תזמון | "רגיל" / "מדויק (איטי ב-40%)" | `accurate_timing` |
| הפרדת שירה | מוצג רק אם `demucs_available` | `separate_vocals` |
| מילון אקורדים | "מז'ור/מינור בלבד" / "רגיל (~170 אקורדים)" / "מלא (600+)" | `chord_vocabulary`: `ismir2017` / `submission` / `full` |
| רמז לתמלול (מתקדם) | שם השיר או מילים נדירות | `prompt` |
| הערכת זמן | "בערך X דקות", לפי משך השיר × 2–3 (או × 0.3 בלי מילים) | חישוב בצד הממשק |
| כפתור "נתח" | | `POST /api/analyze` |

> אם הקובץ כבר נותח בעבר, המנוע מחזיר את התוצאה השמורה מיד (הזיהוי לפי תוכן הקובץ ולא לפי השם).
> ניתוח מחדש בכוח נעשה דרך "ניתוח מחדש".

## 3. מסך התקדמות / תור עבודות

| רכיב | מקור |
|---|---|
| רשימת השלבים עם סימון ✓ / בביצוע / ממתין. הרשימה משתנה לפי האפשרויות (למשל בלי שלב "מתמלל" כשמנתחים אקורדים בלבד) | `stages[]`, `stage` |
| שם השלב הנוכחי בעברית | `stage_label` ("מזהה אקורדים", "מתמלל מילים"...) |
| פס התקדמות כללי | `progress` (0–1) |
| פס התקדמות של השלב | `stage_progress` |
| זמן שעבר / זמן משוער | חישוב בצד הממשק לפי `created` ו-`progress` |
| כפתור ביטול | `POST /api/jobs/{id}/cancel` |
| שגיאה | `status: "error"` + `error` (הודעה בעברית) + כפתור "נסה שוב" |
| בסיום | מעבר אוטומטי לשיר (`song_id`) + התראת Windows אם החלון ממוזער |

עדכונים חיים מגיעים דרך `GET /api/jobs/{id}/events` (Server-Sent Events). אין צורך לדגום את השרת שוב ושוב.

## 4. מסך השיר — המסך המרכזי

### 4.1 כותרת
- שם השיר, מבצע (עריכה בלחיצה) → `meta.title`, `meta.artist`
- **סולם נוכחי** גדול (`meta.key`). כשיש טרנספוזיציה, גם "מקור: X" (`meta.key_original`)
- כשיש קאפו: "קאפו 3 · אצבוע בסולם C" (`view.capo`, `meta.shape_key`)
- קצב BPM (`meta.tempo`), משך (`meta.duration`)
- אזהרה עדינה כש-`meta.key_confidence < 0.4`: "הסולם לא ודאי"

### 4.2 סרגל כלים (הגדרות תצוגה, נשמרות לכל שיר בצד הממשק)
| כלי | ערכים | פרמטר |
|---|---|---|
| טרנספוזיציה | − / + בחצאי טונים, איפוס. מציג "+2" | `transpose` (−6..+5) |
| קאפו | 0–11, עם **הצעות קאפו**: 3 הטובות ביותר ואחוז האקורדים הקשים ("קאפו 3 — רק F קשה") | `capo`, `capo_suggestions[]` |
| רמת פישוט | בסיסי (רק מז'ור/מינור) / רגיל / מלא | `simplify`: `basic`/`standard`/`full` |
| כתיב | C D E / דו רה מי / Do Re Mi | `notation`: `letters`/`solfege_he`/`solfege` |
| דיאזים/במולים | אוטומטי (לפי הסולם) / תמיד ♯ / תמיד ♭ | `accidentals` |
| אקורד בתחילת שורה | להציג או להסתיר את האקורד שממשיך מהשורה הקודמת | `show_carried` |
| גודל גופן, עמודות, מצב לילה, גלילה אוטומטית | בצד הממשק | |
| מצב עריכה | מתג (סעיף 4.6) | |

### 4.3 דף האקורדים
הדף בנוי מרשימת `lines[]` לפי סדר הזמן. יש שני סוגי שורות:

**שורת מילים** (`type: "lyric"`)
- הטקסט: `text`
- מעליו האקורדים: `chords[]`, ולכל אקורד `name` (לתצוגה) ו-`char` (האות שמעליה הוא יושב)
- אקורד עם `carried: true` הוא אקורד שממשיך מהשורה הקודמת. כדאי להציג אותו בגוון חלש יותר
- `char` שווה לאורך הטקסט: האקורד בא אחרי המילה האחרונה, בקצה השמאלי
- מילים שהמנוע לא בטוח בהן (`words[].p < 0.5`) אפשר לסמן בקו תחתון עדין, כדי להזמין תיקון

**קטע נגינה** (`type: "instrumental"`)
- התפקיד (`role`): `intro` פתיחה / `interlude` מעבר / `outro` סיום / `instrumental` שיר ללא מילים
- האקורדים בתיבות: לכל אקורד יש `beats` (מספר פעמות; 4 פעמות = תיבה). אפשר לצייר `| C | C | G | Am |`

**חלוקה לבתים**: לכל שורה יש `section`, ורשימת `sections[]` מפרטת לכל בית `kind`
(`verse` בית / `chorus` פזמון / `intro` / `interlude` / `outro`) ו-`number`.
להציג כותרת "בית 1", "פזמון" וכו'. הזיהוי של פזמון הוא ניחוש: הבית שהטקסט שלו חוזר הכי הרבה.

### 4.4 רצועת האקורדים שבשיר (דיאגרמות)
- כל אקורד שמופיע בשיר מופיע פעם אחת, בתצוגה הנוכחית: `chords_used[]`
- **גיטרה**: `guitar[]`, עד 3 אצבועים. לכל אצבוע `frets`: 6 ערכים ממיתר E הנמוך עד e הגבוה,
  כאשר `null` = לא מנגנים (X), `0` = מיתר פתוח (O), ומספר = סריג. בנוסף `base_fret` (מאיזה סריג
  הדיאגרמה מתחילה), `barre` (ברה, אם יש) ו-`type` (`open` / `E-shape` / `A-shape`).
  כדאי חיצים להחלפה בין האצבועים
- **פסנתר**: `piano[]` עם `midi` (מספר קליד), `role` (`root` שורש / `tone` / `bass`). לצבוע את הקלידים
- בורר גיטרה/פסנתר
- ריחוף או לחיצה על אקורד בדף מדגישים אותו ברצועה

### 4.5 נגן
- ▶ / ⏸ ופס התקדמות. השמע מגיע מ-`GET /api/songs/{id}/audio`, עם תמיכה בדילוג
- **ציר אקורדים** מתחת לפס: קוביות לפי `timeline[]` (`start`, `end`, `name`), בצבע לפי האקורד
- **אקורד נוכחי גדול + האקורד הבא** (לפי `timeline`), מוצג במרכז בזמן נגינה
- הדגשת השורה והמילה הנוכחית, בסגנון קריוקי (`lines[].start/end`, `words[].start/end`)
- גלילה אוטומטית שעוקבת אחרי השורה המתנגנת
- לחיצה על שורה או אקורד מקפיצה את הנגן לזמן שלהם (`time`)
- לופ על בית נבחר, ומהירות נגינה (playbackRate; שינוי מהירות לא משנה את גובה הצליל)
- ⚠ טרנספוזיציה **לא** משנה את השמע, רק את האקורדים. צריך לציין את זה ליד הכפתור

### 4.6 מצב עריכה
| פעולה | התנהגות |
|---|---|
| לחיצה על אקורד | חלון עריכת אקורד (4.7) |
| גרירת אקורד | הזזה לאות אחרת באותה שורה (משנה `char`) |
| לחיצה על אות בלי אקורד | הוספת אקורד בנקודה הזו |
| מחיקת אקורד | מקש Delete או כפתור בחלון |
| עריכת טקסט שורה | עריכה ישירה. המנוע שומר תזמונים אם מספר המילים לא השתנה |
| פיצול / איחוד שורות, הוספה ומחיקה | בצד הממשק. שולחים את כל רשימת השורות |
| שינוי סוג בית | בחירה מתוך verse/chorus/... |
| ביטול/חזרה (Undo/Redo) | בצד הממשק |
| **שמירה** | `PUT /api/songs/{id}` עם כל `lines` ועם `view` הנוכחי |
| **הדבקת מילים נכונות** | חלון עם תיבת טקסט → `POST /api/songs/{id}/lyrics`. מיישר את המילים לשמע ובונה את השורות מחדש **בלי לנתח שוב** (שניות). ⚠ דורס עריכות ידניות, ולכן צריך אישור |
| **חזרה לזיהוי המקורי** | `POST /api/songs/{id}/reset` עם אישור |

### 4.7 חלון עריכת אקורד
- רשת של 12 שורשים (C, C#/Db ... או דו, דו#...) → `GET /api/chords/vocabulary`
- רשימת סוגים: מז'ור, m, 7, maj7, m7, sus4, dim... (`qualities[]`)
- בס (אופציונלי) לאקורד עם קו נטוי (D/F#)
- תיבת הקלדה חופשית ("Am7/G", "לה m7")
- תצוגה מקדימה של האצבוע → `GET /api/chord?name=...`
- ההחלפה נעשית בסולם **שמוצג כרגע**, והמנוע מחזיר אותה לסולם המקור בעצמו

### 4.8 ייצוא ושיתוף
| פורמט | שימוש | נתיב |
|---|---|---|
| טקסט (.txt) | אקורדים מעל מילים, להעתקה לוואטסאפ או פורום | `export?format=txt` |
| ChordPro (.cho) | פורמט סטנדרטי של אפליקציות אקורדים (OnSong, SongbookPro) | `format=chordpro` |
| LRC | כתוביות מתוזמנות | `format=lrc` |
| JSON | גיבוי מלא | `format=json` |
| הדפסה / PDF | הממשק מדפיס את התצוגה שלו (כולל רצועת הדיאגרמות) | בצד הממשק |
| העתקה ללוח | תוכן ה-txt | |

הייצוא תמיד תואם את התצוגה הנוכחית: אותה טרנספוזיציה, קאפו וכתיב.

## 5. הגדרות
- ברירות מחדל לתצוגה (כתיב, פישוט, גודל גופן) ולניתוח (דיוק תזמון, מילון) → `view_defaults`, `analyze_defaults`
- מודל התמלול (אם הותקן יותר מאחד): `whisper_models[]`. `q5_0` מהיר, המלא מדויק מעט יותר
- מיקום הספרייה: `library_dir` (לקריאה בלבד)
- מספר ליבות לתמלול: `threads`

## 6. מצבים והודעות שגיאה
| מצב | הודעה מוצעת |
|---|---|
| המנוע לא עונה | "מנוע האקורדים לא פועל" + כפתור הפעלה מחדש |
| `whisper_ready = false` | "מודל העברית לא מותקן — אפשר לנתח אקורדים בלבד" |
| הקובץ לא נמצא (400) | ההודעה מהשרת (`error`) |
| קובץ השמע של שיר הוזז (404 ב-audio) | "קובץ השמע הוזז או נמחק — הנגן לא זמין", והדף עצמו ממשיך לעבוד |
| שיר בלי מילים שזוהו | הדף מציג רק קטעי נגינה + הצעה "להדביק מילים?" |
| אקורד לא חוקי בעריכה (400) | סימון אדום בתיבה + ההודעה מהשרת |
